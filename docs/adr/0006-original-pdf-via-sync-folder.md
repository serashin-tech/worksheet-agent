# 원본 스토리보드 PDF는 Drive 동기화 폴더 복사로 작업 폴더의 00_입력에 넣는다

원본 스토리보드 PDF(EP12는 45.5MiB)는 Drive 커넥터의 요청 본문 한도(약 10MB)를 넘어 커넥터로 올릴 수 없다. 그래서 플러그인이 PD PC의 Google Drive 데스크톱 동기화 폴더(`G:\`)에 파일을 복사해 시나리오와 같은 `<작업 폴더>/<애니메이션명>/EP<번호>/00_입력`에 넣는다. PDF를 줄여 커넥터로 올리는 방안은 원본이 남지 않아, PD가 매번 직접 올리게 하는 방안은 입력 단계가 늘어 채택하지 않았다. 동기화 폴더를 찾지 못하면 PD에게 `00_입력` 폴더 링크를 주어 직접 올리게 한다.

## Consequences

- 로컬 PC에서 도는 세션(Claude Code, Cowork 로컬)에서만 쓸 수 있고, 클라우드 세션에서는 쓸 수 없다.
- 지정한 작업 폴더가 그 PC의 `G:\`(내 드라이브 또는 공유 드라이브) 아래에 동기화되어 있어야 한다.
- 복사 뒤 Drive에 보이기까지 약 1분이 걸리므로, 검색으로 반영을 확인한 다음 다음 단계로 넘어간다.
