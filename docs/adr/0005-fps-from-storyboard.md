# 초당 프레임은 스토리보드 값을 기본으로 하고 PD가 바꾼다

ADR 0001은 EP12 정답 시트에 맞춰 29.97fps로 고정했지만, 스토리보드 머리글에는 24FPS가 적혀 있고 PD는 에피소드마다 값을 직접 정하기를 원한다(2026-11-24). 그래서 스토리보드 머리글의 값을 기본으로 쓰고, 콘솔의 워크시트 단계에서 PD가 바꾼 값을 화면, 시트의 Sec 수식, 검증이 모두 함께 쓴다. 화면만 바꾸고 시트를 29.97로 두는 방안도 있었으나, 화면과 시트의 러닝타임이 달라져 PD가 어느 값을 믿을지 알 수 없게 되므로 채택하지 않았다.

## Consequences

- EP12 정답 시트(29.97)와 견주는 시험은 FPS를 29.97로 넣어 따로 돌려야 한다.
- `build_worksheet.py`는 overrides의 `fps`를 그대로 Sec 수식에 쓰고, 없으면 기본값 없이 멈춘다. `console_overrides.py`도 cuts.json에 `fps`가 없으면 멈춘다. `verify_worksheet.py`는 시트 수식에서 FPS를 읽어 러닝타임을 계산하고, 요약의 `fps`와 다르면 실패로 보고한다(2026-11-24).
- 토스트가 실제로 어느 FPS로 납품하는지는 확인 전이다(CONTEXT.md의 '납품 FPS').
