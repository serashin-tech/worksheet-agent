# Worksheet 콘솔 로컬 사이트

claude.ai에서는 콘솔을 Artifact로 열고 Google Drive·Google Sheets 커넥터로 저장한다. 그 밖의 곳에서는 `serve_console.py`가 콘솔을 로컬 사이트로 열고, 같은 커넥터 호출을 PC 폴더에서 대신 처리한다. 콘솔 화면과 단계는 같다. 다른 점은 Drive 링크 자리에 PC 폴더 경로를 붙여 넣는다는 것뿐이다.

스크립트 경로는 이 SKILL.md가 있는 폴더 기준 `../../scripts/`다. Python은 늘 `python -I`로 돌린다.

## 1. 폴더 정하기

PD에게 두 폴더의 PC 경로를 받는다.

- **작업 폴더**: 콘솔이 `<애니메이션명>/EP##/00_입력·01_산출·02_작업`을 만들 곳. Google Drive 동기화 폴더(`G:\내 드라이브\…` 또는 `G:\공유 드라이브\…`) 안을 권한다. 그러면 저장한 파일이 Drive에도 올라간다.
- **시리즈 에셋 폴더**: `BG / CH / PR`(필요하면 `Matte`, `2D`) 하위 폴더가 있는 곳.

두 폴더가 같은 상위 폴더 안에 있으면 상위 폴더 하나만 넘겨도 된다. 서버는 넘긴 폴더 밖은 읽지도 쓰지도 않는다.

## 2. 서버 띄우기

```
python -I ../../scripts/serve_console.py --root "<작업 폴더>" --root "<시리즈 에셋 폴더>"
```

- 서버는 끝나지 않는 프로세스다. 백그라운드로 실행하고, 출력의 `콘솔: http://127.0.0.1:8765/` 줄을 확인한 뒤 PD에게 그 주소를 준다. 브라우저는 서버가 연다(`--no-open`이면 열지 않는다).
- 포트가 이미 쓰이고 있으면 `--port 8766`처럼 바꾼다.
- 시연 데이터는 없어도 된다. 콘솔은 빈 상태로 열리고, PD가 시나리오를 올리면 컷 목록을, 스토리보드 PDF를 올리면 썸네일·칸·대사를 서버가 그 파일로 만들어 채운다(스토리보드는 1~2분). 미리 만든 시연 데이터 폴더(`cuts.json·thumbs.json·panels.json·work.json`)로 보여 주려면 `--data "<폴더>"`를 붙인다.

## 3. PD에게 알려 줄 것

1. 상단 "Google Drive 연결 설정"에서 두 연결 확인 버튼을 누르고, 작업 폴더 칸에 작업 폴더 경로를 붙여 넣은 뒤 "폴더 확인"을 누른다.
2. 3단계(에셋)에서 시리즈 에셋 폴더 경로를 붙여 넣는다.
3. 4단계에서 "확정하고 시트 만들기"를 누르면 `02_작업/cuts.json`이 생긴다. 그다음 "시트 만들어 줘"라고 하면 `worksheet-build` 스킬의 로컬 모드로 xlsx를 만든다.
4. 5단계(작업 현황)는 작업 폴더 아래의 xlsx를 시트로 읽는다.
5. 콘솔의 폴더 링크를 누르면 탐색기에서 그 폴더가 열린다.

## 끝내기

PD가 콘솔을 다 썼다고 하면 서버 프로세스를 멈춘다.
